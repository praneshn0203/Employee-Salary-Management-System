\# Employee Salary Management System

\## 1. Introduction

Employee Salary Management System is a Python based project that deals with employee, attendance and salary management.

Through this project, any user can add employee details, view and search employee, record attendance, calculate salary and view salary details.

This project covers basic python concepts like variables, data types, conditional statements, loops, functions, lists, dictionaries, input and output, modular programming etc.

\## 2. Features

Add employee details View all employees Search for an employee Record employee attendance Calculate employee salary Calculate gross salary Calculate deductions Calculate net salary Display salary information Simple menu driven approach Input validation by implementing program logic

\## 3. Technologies

Python 3 Visual Studio Code/Python IDLE Git GitHub

\## 4. Modules

\### Employee Management

This section manages the employee id, name, department and designation


\### Attendance Management

This section is used to record working days, absent and leave days.

\### Salary Management

This section is used to calculate basic salary, allowances, overtime, bonus, deductions,

gross salary and net salary.

\### Reporting

This section displays the employee and salary information.

\## 5. Salary Calculations

Below are the calculations that are involved in this project.

\### Gross Salary

Gross Salary = Basic Salary + Allowance + Overtime + Bonus

\### Net Salary

Net Salary = Gross Salary - Deductions
